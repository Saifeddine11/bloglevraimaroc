## 10. Remaining obstacles to competitive ranking

1. **Not deployed:** the live French page still contains the older version; the English page was not returned from the research cache.
2. **No Search Console evidence:** index coverage, query ownership and cannibalization cannot yet be measured.
3. **Authority gap:** Netflix and established entertainment/local publishers have stronger topical and backlink authority.
4. **Public corroboration gap:** Accrocar and Dune Films do not currently publish a named public case study for this production. A carefully worded public first-party statement would strengthen corroboration.
5. **Repository link debt:** 42 unrelated broken internal links should be repaired because site-wide crawl quality can affect the broader domain.
6. **Freshness competition:** this query changes with every Netflix announcement. The pillar should be updated only when a substantive, verified development occurs.
7. **No ranking guarantee:** first position is an objective, not an outcome that can be promised.
